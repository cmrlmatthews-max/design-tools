How projects work

General notes · moving work from tool to tool

A project is one file that holds the work of every tool for one design study. Each tool adds its own part: the site, the massing, the parking, the facade. The next tool reads the parts before it.

1 · Start a project

  1. Select New project below. Type a name. Select Create. The project becomes the open project.
  2. Or start from a site: open the Site Model, find an address, then select Send to Mid-Rise Generator in its top bar. The Site Model makes a project named after the address.
  3. Or start in any tool: open its Project menu in the top bar and select New project.

2 · Work in a tool

  1. Select a project in the Project schedule. Its status changes to Open.
  2. In Tools, select Open with project on the tool you want. The tool shows the project name in its top bar.
  3. Work in the tool. The tool saves its part of the project about one second after each change. The project needs no save button.

3 · Move to the next tool

  1. In the tool, open the Export menu and select Send to the next tool. In the Site Model, the Send to buttons are in the top bar.
  2. The tool saves the project, then opens the next tool with the same project. The next tool reads the parts it needs.
  3. Or come back to this page and select Open with project on the next tool. A tool with work in the project shows Has data and the date.

5 · Rules

  • Each tool changes only its own part. It never changes the work of another tool.
  • After you change an earlier tool, open the later tool again. It reads the new data when it opens.
  • A project holds one massing. The Tower Generator or the Mid-Rise Generator writes it, whichever saved last.
  • Each tool also has its own saved options (the Option menu). Options stay in that tool. The project holds only the current design of each tool.
  • Select Close next to the open project name to stop using it. The tools then open on their own, with no project.
  • The Plate Planner fills the plates of the massing in the project. After you change the massing, open the Plate Planner again and select Re-fill; it shows a notice when the massing is newer than its fill.
  • The Sun Study lives in the Tower Generator (View tab). It writes the sun dates and sun hours into the project; the Facade Studio uses them for its sun exposure numbers.

6 · Keep a copy and move between devices

Caution: projects live in this browser on this device only. Clearing the browser data deletes them. Export a project to keep a copy.

  1. Select the project in the Project schedule, then select Export. A file named name.cmrlm.json downloads.
  2. Move the file to the other device, for example with AirDrop or the Files app.
  3. On the other device, open this page, select Import, and choose the file. A project that is already on that device comes in as a copy named “Name (2)”.
