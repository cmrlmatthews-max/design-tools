How projects work

General notes · moving work from tool to tool

1 · What a project is

A project is one file that holds the work of every tool for one design study. Each tool writes one part of the file. That part is the section of the tool. A tool reads the sections of the tools before it.

The tools run in this order: Site → Massing (Tower or Mid-Rise) → Plates → Parking → Facade → Sun → Grading → Egress (planned). The Tools list on this page uses the same order.

  • Open project: the project that the tools on this page open. The Project schedule marks it Open.
  • Site layer: the project site from the Site Model. It shows the ground, the site boundary, roads, water, trees, and neighbor buildings. Every tool draws it.
  • Placement: the position of the building on the site. It is X (east), Y (north), rotation, and base elevation. The base elevation is the elevation of the ground floor, in feet.

Select Tour at the top of this page for a five-slide tour.

2 · Start a project

Start a project on this page or in the Site Model. Use the Site Model when the design has a real site.

On this page

  1. Select New project below the Project schedule.
  2. Type a name. Select Create. The new project becomes the open project.

In the Site Model

  1. Open the Site Model. Type an address. Select Go.
  2. In the top bar, select Send to Tower Generator or Send to Mid-Rise Generator.
  3. With no open project, the Site Model makes a project. The project has the name of the address.
  4. The massing tool opens with the project. Go to section 3.

A tool can also start a project. Open the Project menu in its top bar. Select New project.

To open a saved project, select it in the Project schedule. Its status changes to Open.

3 · Take the site into a massing tool

  1. Select the project in the Project schedule.
  2. In Tools, select Tower Generator or Mid-Rise Generator on the Massing card. The tool opens with the project.
  3. Look at the top bar. The tool shows the project name there.
  4. Look at the model. The site layer shows the ground, roads, water, and trees. Neighbor buildings are solid grey blocks with dark edges.
  5. Drag the building on the ground to move it. The base elevation follows the ground. Each drag is one undo step.
  6. Drag the rotation handle to turn the building. It turns in 5-degree steps.
  7. To type exact values, open the Site tab. Type X, Y, rotation, and base elevation under Placement.
  8. To put the building at the center of the site, select Center on site in the Site tab. The base elevation goes to the ground there.
  9. To hide the site layer, turn off Site in the View tab. The placement and the numbers do not change.
  • On a slope, the building cuts into the ground. The Grading Sketch sets the pads later.
  • Neighbor buildings in the site layer do not change a number. For sun hours and metrics, select Context from site in the Site tab. It makes context blocks from the neighbors within the radius. The context blocks cast shadows in the Sun Study.
  • A standalone Parking Deck moves the same way: drag it, and turn it with the handle. A wrap deck or a podium follows the massing.
  • The Plate Planner and the Facade Studio show the site under the massing. You cannot drag the building there. The Grading Sketch draws its own ground and shows the rest of the site on it.

4 · Move to the next tool

  1. Do the work in the tool. The tool saves its section about one second after each change. There is no save button.
  2. Open the Export menu. Select Send to and the next tool. In the Site Model, the Send to buttons are in the top bar.
  3. The tool saves the project. Then it opens the next tool with the same project.
  4. The next tool reads the sections it needs when it opens.
  5. Or come back to this page. Select Open on the card of the next tool. The tool opens with the open project.
  6. The Site Model card says Open with project while a project is open. The Massing card has two buttons: Tower Generator and Mid-Rise Generator.
  7. Look at the tool cards on this page. A tool with work in the project shows Has data and the date.

6 · Rules

  • One tool, one section. Each tool writes only its own section. It never changes the work of another tool.
  • Reopen later tools. After you change an earlier tool, open each later tool again. A tool reads the new data only when it opens.
  • Re-fill in the Plate Planner. The Plate Planner keeps its fill when the massing changes. Use the steps below to take the new massing.
  • Unlimited site. A new Tower or Mid-Rise design has an Unlimited site. Unlimited means no site line, no setbacks, and no site checks. A project site from the Site Model gives the site line: its boundary draws on the ground. For setbacks and site checks, set Shape to Rectangle or Polygon in the Site tab.
  • One massing per project. The Tower Generator or the Mid-Rise Generator writes it. When the project holds a massing from the other tool, the tool asks first. Until you select Replace, the tool does not save to the project.
  • Sun Study. The Sun Study is in the Tower Generator (View tab). It writes the sun dates and sun hours. The Facade Studio uses them for its sun exposure numbers.
  • Options stay in the tool. Each tool keeps its own saved options (the Option menu). The project holds only the current design of each tool.
  • Newer version. A card that shows Newer version holds work from a newer version of that tool. The tool opens it read-only.
  • Close. Select Close next to the open project name to stop using it. The tools then open with no project.

Re-fill the plates after a massing change

Caution: Re-fill recomputes every unlocked unit from the mix. A locked unit keeps its outline and its type.

  1. Change the massing in the Tower Generator or the Mid-Rise Generator.
  2. Open the Plate Planner with the project. A notice says “The massing changed after this fill.”
  3. Select Re-fill in the notice. The fill takes the new massing.

7 · Keep a copy and move between devices

Caution: projects live in this browser on this device only. Clearing the browser data deletes them. Export a project to keep a copy.

  1. Select the project in the Project schedule. Select Export. A file named name.cmrlm.json downloads.
  2. Move the file to the other device, for example with AirDrop or the Files app.
  3. On the other device, open this page. Select Import. Choose the file.
  4. A project that is already on that device comes in as a copy named “Name (2)”.
