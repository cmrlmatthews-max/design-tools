## Approved features

1. **Select by clicking.** Click or tap a segment, the podium, the crown, a carve, or a context block. Outline the selection. Open its controls in a selection card at the top of the panel. Shift-click (Mac) or a "Select more" toggle (iPad) adds items. Click empty space or press Escape to clear.
2. **Handles in the 3D view.** On the selected item: move arrows (east–west, north–south, in plan axes), a top handle to add or remove floors (segments) or change height (context blocks), side handles for width and depth. Live dimension label during a drag. A handle drag never rotates the camera (disable OrbitControls while a handle is active). Handle hit size ≥ 44 CSS px on touch. Handles work in the axon and the ortho views.
3. **Snapping.** Targets: grid (5 or 10 ft), site edges, setback lines, edges and centers of segments and the podium, context block edges and centers. Orange dashed guide lines show the active snap. Snap toggle in the top bar. Hold Option/Alt during a drag to skip snapping.
4. **Program.** Program buttons on the selection card change the program of every selected item. Diagram style default `colorBy: "program"`. A small color legend shows in Diagram style. A color swatch shows on each segment row.
5. **Copy segment.** "Copy above" and "Copy below" insert an identical segment directly on top of or under the selected one. Segments over it move up (the stack order does this already).
6. **Layout (Direction A).** Tabs in the panel in this order: Form, Program, View, Site. Short top bar: Option menu (presets, Save, Duplicate, Rename, Delete, Compare), Undo/Redo, Model/Diagram, Snap toggle, Export menu (Image, AI-ready image, AI Prompts, Export JSON, Import JSON). Four metrics always visible (GFA, FAR, height, floors); one tap expands the rest; the warning count stays visible.
7. **Presets.** Rename the old city-named L preset to "L-shaped multifamily on podium". Add "U-shaped multifamily on podium". Use only generic names in ids, tests, and notes. Done: the U preset uses a 15% core so the core fits in its 50 ft arm.
8. **Mac shortcuts.** 1–6 views (Axon, N, E, S, W, Plan), D Model/Diagram, Delete removes the selection, Command+D copies above, Escape clears the selection. Ignore shortcuts while focus is in a text field.

## Hooks the layout agent provides for the selection agent

- A container `#selection-card` at the top of the controls panel, above the tabs, hidden when nothing is selected.
- `UI.openItem({ kind, index })`: switches to the right tab and opens and scrolls to that item's section.
- `UI.setProgramForItems(items, program)`: one undo step.
- The Snap toggle in the top bar writes `state.view.snap` (`{ on: true, grid: 5 }`), part of the view state.

## Snap module notes for the selection agent (from the snap author)

- Signatures: `collectSnapTargets(state, plates, { exclude })`, `snapMove(box, delta, targets, { tolerance, grid, enabled })` → `{ dx, dy, guides }` (guides also carry `feature: "min"|"max"|"center"`), `snapEdge(value, axis, targets, { tolerance, grid, enabled, span })` → `{ value, guide }`, `snapLength(length, { step })`, plus `itemBox(state, plates, { kind, index })` → box | null.
- Box per item: use `itemBox`. Segment = bbox of its first tower plate; podium = its plate bbox; context = x ± w/2, y ± d/2; crown and carve return null (build the box yourself, or skip snapping).
- Pass the PRE-drag box and the CUMULATIVE drag delta every frame.
- Build targets once at drag start with `exclude` = the moving item.
- Tolerance in ft = 12 px × ft-per-CSS-px at the drag point (ortho: `12 * (camera.top - camera.bottom) / camera.zoom / canvasCssHeight`; axon: project two points 1 ft apart on the drag plane). Clamp 0.5–20 ft. Use 16 px on touch.
- `grid: state.view.snap.grid`, `enabled: state.view.snap.on && !event.altKey`.
- Grid guides have `kind: "grid"`; do not draw them (they would clutter).
- Resize: `snapEdge` on the moving edge (axis "x" for east/west handles, "y" for north/south), derive the new width/depth, then `snapLength` (1 ft) when no target hit.
- Context lines are left out when `state.context.show === false`.
