# Site Model help: Remove buildings

Phase C copy. Phase B pastes the paragraph below into the Site Model help block (`build/site/04_ui.js`) under a section titled **Remove buildings**.

---

Click a building in the 3D view to open its card. Select Remove on the card to take the building out of the site. A dashed outline stays on the ground where the building stood. Select Restore on the card to put the building back. Select Restore all in the panel to put back every removed building. The list of removed buildings stays when you load the same address again. Every other tool and every export leaves out a removed building. The DXF file draws its ground outline on the layer BLDG-REMOVED. A removed building casts no shadow.
